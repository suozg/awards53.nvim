Плагін awards53 (Управління структурованими даними в Neovim)
│
├── 1. Блок обробки даних (Перетворення форматів)
│   │
│   ├── parser.lua (Розбір даних)
│   │   └── Функції: Зчитують сирий текст із буфера або файлу і розбивають його на логічні
│   │                структури Lua (таблиці, поля, рядки), щоб плагін розумів документ.
│   │
│   └── serializer.lua (Генерація тексту)
│       └── Функції: Беруть змінені дані з Lua-таблиць і збирають їх назад у правильний 
│                    текст, зберігаючи форматування (наприклад, структуру Org-mode) 
│                    перед записом.
│
├── 2. Блок керування станом та логікою ("Пам'ять" програми)
│   │
│   ├── state.lua (Ядро керування)
│   │   └── Функції: Зберігають інформацію про відкриті записи та закладки, ведуть 
│   │                історію змін для скасування дій (undo), а також відповідають за 
│   │                навігацію (перехід до наступної/попередньої картки).
│   │
│   └── utils.lua (Утиліти)
│       └── Функції: Виконують незалежні завдання: математична перевірка (валідація) РНОКПП, 
│                    очищення тексту від невидимих символів та виправлення неправильної 
│                    розкладки клавіатури при введенні команд.
│
└── 3. Блок інтерфейсу та пошуку (Взаємодія з користувачем)
    │
    ├── ui.lua (редактор карток), editor.lua (редактор поля)
    │   └── Функції: Відмальовують текст у буфері, застосовують правила підсвітки 
    │                синтаксису та прив'язують гарячі клавіші для виклику команд плагіна.
    │
    ├── status.lua (Рядок стану)
    │   └── Функції: Збирають поточну статистику (номер запису, активний режим) і 
    │                виводять її у кастомний статус-бар внизу екрана.
    │
    └── searchtxt.lua (Пошуковий рушій)
        └── Функції: Виконують запити до текстових файлів (включно із зашифрованими GPG) 
                     та баз даних SQLCipher. Створюють плаваюче вікно (floating window) 
                     для зручного відображення результатів пошуку.
