# awards53.nvim

Плагін для [Neovim](https://neovim.io/) для підготовки та редагування нагородних листів у форматі Org-mode.

Плагін призначений для роботи з базами карток `Awards53`, у яких кожна картка складається з кількох текстових полів. Він також підтримує створення документів `Documents53` із шаблонів LibreOffice, конвертацію таблиць із Word/ODT та пакетну обробку файлів через shell-скрипт.

## Можливості

- інтерактивне редагування карток Awards53 у спеціальному вікні;
- навігація між картками та полями;
- створення, видалення й переміщення карток;
- створення, видалення та перестановка полів;
- пошук по вибраному полю або полю за замовчуванням;
- сортування українського тексту;
- закладки карток;
- копіювання, вирізання та вставка карток;
- Undo/Redo та перегляд історії змін;
- перевірка РНОКПП у тексті;
- очищення невидимих символів після імпорту з офісних документів;
- захист від одночасного редагування одного Awards53-документа;
- створення документів із шаблонів `.org` та `.odt`;
- захист технічних полів Documents53;
- конвертація Word/ODT-таблиць у структуру Awards53.

## Встановлення

### lazy.nvim

```lua
{
    "suozg/awards53.nvim",
    config = function()
        require("awards53").setup()
    end,
}
```

За потреби параметри можна передати в `setup()`:

```lua
require("awards53").setup({
    separator = "::",
    record_separator = "===",
    section = "AWARDS53",
    default_sort = "1",
})
```

### Структура конфігурації

Для функцій Documents53 плагін за замовчуванням очікує шаблони в каталозі:

```text
~/.config/nvim/templates/templates53
```

Цей шлях можна змінити у модулі конфігурації документів:

```text
nvim/lua/awards53/documents/config.lua
```

## Залежності

Для базової роботи плагіна достатньо Neovim і `lazy.nvim` або іншого менеджера плагінів.

Для додаткових можливостей потрібні зовнішні програми:

- `pandoc` — конвертація Word/ODT-файлів;
- `libreoffice` — автоматична конвертація старих `.doc` у `.docx`;
- `fzf` — вибір шаблонів Documents53;
- `xkb-switch` — необов'язкова підтримка перемикання розкладки клавіатури у конфігурації Neovim із цього репозиторію;
- `dwmblocks` — необов'язково, використовується для оновлення статусної панелі.

Перевірити наявність програм можна так:

```bash
command -v nvim
command -v pandoc
command -v libreoffice
command -v fzf
```

## Команди

### Awards53

```vim
:Awards53
```

Відкриває редактор карток. Якщо поточний буфер не містить секцію `AWARDS53`, плагін може знайти вже відкритий Awards53-буфер або створити базову структуру в поточному буфері.

Файл із базою має містити заголовок:

```org
* AWARDS53
```

### Documents53

```vim
:Documents53
```

Відкриває меню роботи з шаблонами Documents53.

### Конвертація документа

```vim
:Documents53Convert
```

Конвертує поточний Awards53 або Documents53-документ у відповідний вихідний формат, який підтримує модуль конвертації.

### Аббревіатури

```vim
:Awards53abbr
```

Відкриває редактор списку аббревіатур.

### Команди у вікні редактора карток

У спеціальному вікні доступні локальні команди:

```vim
:W
:Q
:Q!
```

- `:W` — синхронізувати картки з вихідним буфером і зберегти файл;
- `:Q` — закрити редактор;
- `:Q!` — примусово закрити редактор.

Оскільки вікно карток має тип `acwrite`, стандартні `:w` та `:q` перехоплюються локальними скороченнями й направляються до `:W` та `:Q`.

## Формат Awards53

Мінімальна база виглядає так:

```org
* AWARDS53

Іван Петренко
::
старший сержант, командир відділення
::
За сумлінне виконання службових обов'язків.
===

Петро Коваленко
::
солдат
::
За високий професіоналізм.
```

Правила формату:

- `* AWARDS53` — початок бази;
- `::` — роздільник полів усередині картки;
- `===` — роздільник карток;
- наступний Org-heading (`*`, `**` тощо), крім `* AWARDS53`, завершує блок Awards53;
- поля можуть містити декілька рядків;
- кількість полів визначається за найбільшою кількістю полів серед карток.

Роздільники можна змінити через `setup()`:

```lua
require("awards53").setup({
    separator = "::",
    record_separator = "===",
    section = "AWARDS53",
})
```

## Клавіші редактора карток

### Навігація

| Клавіша | Дія |
| --- | --- |
| `h` / `l` | попередня / наступна картка |
| `[[` / `]]` | перша / остання картка |
| `H` / `L` | перейти на 5 карток назад / уперед |
| `g` | перейти до картки за номером |
| `j` / `k` | наступне / попереднє поле |
| `f` | перейти до поля за номером |
| `m` | встановити або зняти закладку |
| `]m` / `[m` | наступна / попередня закладка |

### Редагування

| Клавіша | Дія |
| --- | --- |
| `i` | редагувати поточне поле |
| `A` | додати нову картку |
| `F` | додати нове поле |
| `F-` | додати поле зі значенням `-` |
| `B` | видалити поточне поле |
| `dd` | скопіювати та видалити поточну картку |
| `yy` | скопіювати поточну картку |
| `p` | вставити картку після поточної |
| `J` / `K` | перемістити вміст поля вниз / вгору |
| `u` | скасувати дію |
| `<C-r>` | повторити дію |
| `U` | відкрити історію змін та перегляд diff |
| `dp` | перемістити картку у `fork.org` |

### Пошук і сортування

| Клавіша | Дія |
| --- | --- |
| `/` | пошук у полі за замовчуванням |
| `g/` | вибрати поле та виконати пошук |
| `n` / `N` | наступний / попередній результат пошуку |
| `S` | сортувати картки за полем за замовчуванням |
| `O` | спеціальне сортування, яке ставить офіцерів першими |
| `0` | стиснути порожні поля по всій базі |
| `?` | відкрити довідку |

Для переходу або вибору поля можна використовувати числовий префікс, наприклад:

```text
5g    перейти до картки №5
3f    перейти до поля №3
```

## Захист від повторного відкриття

Плагін не дозволяє одночасно редагувати один Awards53-документ у кількох редакторах.

Використовуються два рівні захисту:

1. внутрішня перевірка відкритого редактора в поточному процесі Neovim;
2. lock-файл поруч із документом:

```text
file.org.awards53.lock
```

Lock створюється атомарно, містить PID процесу-власника та перевіряється при повторному відкритті. Якщо процес завершився аварійно, застарілий lock може бути очищений автоматично.

Не видаляйте активний `.awards53.lock`, якщо документ відкритий в іншому Neovim.

## Documents53 і шаблони

Шаблон Documents53 може містити службові поля Org-mode, наприклад:

```org
#+ODT_STYLES_FILE: /path/to/style.odt
#+DOC53_REQUIRED: #+DOC53_NAME,#+DOC53_POSITION
```

Під час створення документа плагін:

- читає `.org`-шаблон;
- додає службову інформацію про необхідні поля;
- додає шлях до `.odt`-стилю;
- створює новий `.org`-файл із датою та часом у назві.

Каталог шаблонів за замовчуванням:

```text
~/.config/nvim/templates/templates53
```

Скрипт `bash/doc53-picker` використовується для вибору каталогу шаблону через `fzf`.

## Імпорт таблиць із Word та ODT

Скрипт:

```bash
bash/convert_to_AWARDS53.sh файл.docx
```

Підтримуються, зокрема:

```bash
bash/convert_to_AWARDS53.sh файл.docx
bash/convert_to_AWARDS53.sh файл.odt
bash/convert_to_AWARDS53.sh файл.doc
bash/convert_to_AWARDS53.sh *.docx
```

Для таблиці скрипт використовує такі роздільники:

- `::` — між комірками одного рядка;
- `===` — між рядками таблиці;
- `* AWARDS53` — заголовок бази.

Для декількох вхідних файлів скрипт створює окремі `.txt`-файли. Якщо конвертовано більше одного файла, він пропонує об'єднати їх у:

```text
combined_awards.txt
```

Перед використанням переконайтеся, що скрипт має право на виконання:

```bash
chmod +x bash/convert_to_AWARDS53.sh
chmod +x bash/doc53-picker
```

## Структура репозиторію

```text
bash/
├── convert_to_AWARDS53.sh   # імпорт таблиць Word/ODT
└── doc53-picker              # вибір шаблону через fzf

nvim/
├── init.lua                  # приклад конфігурації Neovim
├── lua/awards53/
│   ├── init.lua              # ініціалізація плагіна
│   ├── commands.lua          # команди та синхронізація з буфером
│   ├── parser.lua            # розбір формату Awards53
│   ├── serializer.lua        # запис даних назад у текст
│   ├── state.lua             # стан, навігація та операції з картками
│   ├── ui.lua                # інтерфейс редактора карток
│   └── documents/             # робота з Documents53
└── lua/config/               # приклад конфігурації Neovim
```

## Обмеження

- одночасно редагується один Awards53-документ у межах поточного стану плагіна;
- для імпорту та конвертації потрібні зовнішні програми;
- формат використовує текстові роздільники `::` і `===`, тому їх не слід використовувати як окремі рядки всередині звичайного тексту поля;
- перед масовими операціями з даними рекомендується мати резервну копію файлу;
- автодетекція Awards53 виконується під час відкриття буфера, якщо перший рядок містить секцію `AWARDS53`.
